# SANKET

SANKET (संकेत, "early sign") predicts a mobile-signal drop a few seconds before it happens, so a phone can save
what matters first: a delivery order, a half-finished download, an upload. It was built for PRAYAS problem
PRAYAS-COMP-26-S-020 at Terna Engineering College.

| [`research/`](research) | The PRAYAS study: simulator, real-data evaluation, results, interactive dashboard |
